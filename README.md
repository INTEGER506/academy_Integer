# Academy Management System

## 개발환경
- IDE: IntelliJ IDEA
- Server: Tomcat9
- Java: JDK SE 11
- Build: Gradle
- RDBMS: Oracle 21c XE
- ORM: Mybatis
- Template Engine: JSP
- Spring Boot:  2.7.18

## 로그인
- 어드민 계정으로 로그인 후 사용자 계정 생성으로 로그인 ID와 임시 비밀번호 생성 후 사용자 로그인 가능
  - 어드민 계정은 /resources/static/dummy.sql 참고
